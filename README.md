# Vincent BALAZUT's Linktree

A modern React-based Linktree landing page built with a sleek dark aesthetic.

## Features

- Modern React architecture
- Responsive design for all devices
- Beautiful gradient background with overlay
- Social media links (LinkedIn, X)
- Smooth animations and transitions
- Optimized performance

## Getting Started

### Prerequisites
- Node.js 14+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
```

## Deployment

The app can be deployed to:
- **Vercel**: `npm i -g vercel && vercel`
- **Netlify**: Connect your GitHub repo directly
- **GitHub Pages**: Follow React build instructions

## Project Structure

```
src/
├── components/      # React components
├── styles/         # Component-specific CSS
├── icons/          # Social media icons
├── assets/         # Images (profile, background)
├── App.js          # Main App component
└── index.js        # React entry point
```
